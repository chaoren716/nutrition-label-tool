# 营养标签审核平台

GB 28050-2025 · 《中国食物成分表 第6版》· 零外部依赖

## 使用方式

### 方式一：本机使用（最推荐）

双击 `index.html` 即可。完全离线，无需网络。

### 方式二：局域网 + 公网

```bash
# 终端进入本目录
bash server.sh
# 本机：http://localhost:8080
# 局域网：http://你的IP:8080
```

需要公网访问时：
```bash
bash server.sh 8080 public
# 会显示 ngrok 公网地址
```

## 功能

| Tab | 功能 |
|-----|------|
| 配方输入 | 粘贴 Excel 数据（配料名 Tab 重量），或手动搜索添加，实时预览营养成分 |
| 营养成分表 | 每100g / 每包 / 每盒，NRV% 超标预警，导出标签图片 |
| 标签检查 | 7项标示、致敏物质、配料排序自动检查 |
| 标签审核 | 上传标签照片，对照测算值手动审核，自动判定合规性 |

## 数据来源

- CFCT-6 —《中国食物成分表 第6版》
- LIT — 公开发表科学文献
- LABEL — 市售产品标签数据

> ⚠️ 测算结果仅供内部参考，正式标签须以检测报告为准。
