# 营养标签工具

基于 GB 28050-2025《预包装食品营养标签通则》和《中国食物成分表 第6版》的营养成分表测算与标签合规检查工具。

**正式网址：https://chaoren716.github.io/nutrition-label-tool/**

## 使用方式

### 方式一：网页访问（推荐）

任何设备浏览器打开 **https://chaoren716.github.io/nutrition-label-tool/** 即可使用。无需安装任何软件，手机、平板、电脑均可。

### 方式二：本地双击使用

直接双击 `index.html` 即可在浏览器中打开。无需安装任何软件。

### 方式二：局域网共享

```bash
bash server.sh
# 同一 WiFi 下的设备访问 http://你的电脑IP:8080
```

### 方式三：公网访问（任何有网络的地方都能用）

**首次使用需要配置 ngrok（只需一次）：**

1. 打开 https://ngrok.com 注册免费账号
2. 登录后复制你的 authtoken
3. 终端执行：`ngrok config add-authtoken 你的token`

**之后每次使用：**

```bash
bash server.sh 8080 public
```

终端会显示一个 `https://xxx.ngrok-free.app` 的公网地址，任何联网设备输入这个地址即可访问。URL 每次启动会变化，免费版即可满足日常使用。

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+1 / Cmd+1 | 配方输入 |
| Ctrl+2 / Cmd+2 | 营养成分表 |
| Ctrl+3 / Cmd+3 | 标签检查 |
| Ctrl+S / Cmd+S | 保存配方 |
| Ctrl+E / Cmd+E | 导出标签图片 |

## 功能

1. **配方输入** — 上传 Excel 或手动添加配料，实时预览营养成分表
2. **营养成分表** — 每100g / 每包 / 每盒 三维展示，NRV% 超标自动预警
3. **标签检查** — 自动检查 7 项强制标示、致敏物质、配料排序、NRV% 一致性
4. **标签预览** — Canvas 渲染标准格式营养成分表，支持导出 PNG
5. **原料库管理** — 内置 70+ 种原料数据，支持新增和修改

## 数据来源

- CFCT-6 — 《中国食物成分表 第6版》标准版
- LIT — 公开发表科学文献
- LABEL — 市售正规产品标签数据
- EST — 基于同类原料的合理估算

> ⚠️ 本工具测算结果仅供内部参考，正式产品标签须以 CMA/CNAS 认证检测机构出具的检测报告为准。
